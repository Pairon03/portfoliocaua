- **Projetos:** ClipFlow Studio, AB Transportes, FitCore, OrçaFlow IA, site da Korvex, CAGE e EcoMinds, com filtros por Korvex, Pessoais e Acadêmicos

## Rodar localmente

Abra o `index.html` no navegador ou sirva a pasta:

```bash
npx serve .
```
